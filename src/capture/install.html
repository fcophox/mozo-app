Capturador HTML → Figma

Arrastra este botón a tu barra de marcadores:

→ Figma
  1. Abre la página que quieras importar y ajusta el ancho de la ventana (será el ancho del frame).
  2. Haz clic en el marcador → Figma.
  3. Pulsa Copiar JSON (o Descargar).
  4. En Figma: Plugins → Development → HTML to Figma (local), pega y pulsa Importar.
