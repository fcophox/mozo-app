Clona sitios web y llévalos a Figma

Captura fondos, elementos, logotipos y estructura para seguir trabajando el diseño en Figma.

Arrastra este botón a tu barra de marcadores:

__MOZO_MARK__Mozō

1. Captura la página

  1. Abre la página que quieras importar y ajusta el ancho de la ventana (será el ancho del frame).
  2. Haz clic en el marcador Mozō y espera a que termine.
  3. Pulsa Copiar JSON o Descargar (guarda un archivo .mozo.json).

2. Instala el plugin de Figma

Descarga el plugin e instálalo una sola vez en Figma Desktop:

Descargar plugin para Figma (.zip)
  1. Descomprime el archivo: se crea la carpeta mozo-figma-plugin.
  2. Abre Figma Desktop (la versión web no permite instalar plugins en desarrollo).
  3. Ve a Menú → Plugins → Development → Import plugin from manifest…
  4. Elige el archivo manifest.json de esa carpeta. Mozō aparecerá en Plugins → Development.

3. Sube el JSON a Figma

  1. Abre el archivo de Figma donde quieras la página.
  2. Ve a Plugins → Development → Mozō.
  3. Pega el JSON copiado en el cuadro de texto, o arrastra ahí el archivo .mozo.json (también puedes pulsar elegir archivo).
  4. Pulsa Importar: se crea un frame con capas editables del ancho que tenía la ventana.
